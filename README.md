## 📌 About the Project

This project is part of my Data Analytics Internship at VirtualWorks.

The objective of this assignment is to understand the fundamentals of data cleaning
and structural validation using Microsoft Excel. Data cleaning is an essential step
in data analytics because raw datasets may contain duplicate records, missing values,
inconsistent formats, and other data quality issues.

This assignment focuses on preparing data for accurate, reliable, and meaningful analysis.

## 🎯 Objectives

- Identify and handle duplicate records.
- Detect and manage missing values.
- Identify inconsistencies in data formats.
- Perform structural validation of the dataset.
- Improve data quality and maintain data integrity.
- Prepare a clean and organized dataset for further analysis.
